# Company Applicant Stats

```
pip install -r requirements.txt
streamlit run app.py
```

- `data/offline_attended_pool.csv` — Bucket data (static)
- `data/assessment_pool_main.csv` — Assessment pool with TR1/TR2 statuses (static)

Replace those two files (same names) when the pools are refreshed, or upload new
versions from the sidebar for a one-off run.

Per company: upload the applications CSV (with Product) and the mobile + resume CSV.
